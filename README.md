## 🚀 What I'm working on

- 🗽 **[NYCSim](https://github.com/erithy25/Map-New-York)**: a 1:1 drivable New York City. Every building footprint and height from NYC Open Data, real LiDAR roof geometry, real lanes, one-ways and speed limits, live weather. Python data pipeline, C++17 simulation core with tests, assets generated in Blender, assembled in Unreal Engine 5.4.
- 🏠 **[HOMEWATCH](https://github.com/erithy25/ct-OS)**: a private, local home-awareness center. Live camera wall, on-device detection of people, vehicles and packages, property zones and alerts. Everything runs on my own machine, nothing is uploaded.
- 🧠 **[ENGRAMM](https://github.com/erithy25/engramm)**: hyperdimensional computing (VSA) research. Every benchmark preregistered before measurement. 79.3% on WiLI-2018 language ID, 94.6% on MNIST, all trained on a MacBook Air.
