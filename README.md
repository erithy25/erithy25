## 🚀 What I'm working on

- 📦 **BLACKBOX** — a tamper-proof flight recorder for AI agents. Records what an agent was told, allowed to do, and actually did — sealed into a hash chain with replay & diff. Because "the logs say so" isn't proof.
- 🧠 **ENGRAMM** — hyperdimensional computing (VSA) research. Every benchmark preregistered before measurement, every result independently reproduced. 79.3% on WiLI-2018 language ID, 94.6% on MNIST — all trained on a MacBook Air.
- 🔮 **Vera** — a local-first macOS AI assistant. Tauri v2 + Rust + SQLite + Ollama, AES-GCM encrypted capture, shipped as a signed .dmg → [vera-sandy.vercel.app](https://vera-sandy.vercel.app)
