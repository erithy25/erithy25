## 🚀 What I'm working on

- 📦 **[BLACKBOX](https://github.com/erithy25/blackbox)** — a tamper-proof flight recorder for AI agents. Records what an agent was told, allowed to do, and actually did — sealed into a hash chain with replay & diff. Working v0.1 prototype in the repo.
- 🧠 **[ENGRAMM](https://github.com/erithy25/engramm)** — hyperdimensional computing (VSA) research. Every benchmark preregistered before measurement, every result independently reproduced. 79.3% on WiLI-2018 language ID, 94.6% on MNIST — all trained on a MacBook Air.
- 📐 **[Grid Delivery Network](https://github.com/erithy25/grid-delivery-network)** — spec-first engineering of a multi-tenant B2B SaaS for grid connection project delivery. No claim without evidence.
